# Legacy parity inventory

## Control rule

This inventory is the cutover control surface. Discovered behavior defaults to
**Preserve** or **Replace equivalently**. Retirement requires explicit user
approval recorded in an ADR and in this inventory. Feature lists are
non-exhaustive: an undiscovered legacy behavior is an open parity obligation,
not permission to remove it.

No credential values, private URLs, Calendar IDs, student identities, browser
cookies, OAuth data, or sensitive response bodies were inspected or copied
into this document.

## Observed continuity snapshot

The safely reduced snapshot on 2026-08-08 established shape and scale, not
business truth:

- the catalog contained multiple displays, dozens of dates, and legacy fields
  spanning attendance, Calendar, Classroom, Sheets, Slides, forms, QR, and
  provenance;
- configuration contained timezone, timing, check-in visibility, media, and a
  legacy unused public-base field;
- class content and vocabulary were populated; vocabulary selection history was
  non-empty;
- the current override and live assignment-cache files were structurally valid
  but empty at the observation point;
- attendance/quick-link contracts contained several classes and extensive
  current-target metadata;
- reconciliation state contained per-day fingerprints and successful historical
  records, while the latest observed Calendar run was safely skipped for a
  repair-required PowerSchool session with zero Calendar changes;
- the latest reduced classroom health report was ready/healthy and had only
  informational issues.

These observations do not authorize discarding empty-at-the-time features or
assuming counts remain current.
